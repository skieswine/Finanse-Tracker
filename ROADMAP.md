## Відомі проблеми / зауваження
- Нові рядки UI додавати в **усі 4** словники (TS не дасть забути). Переклади de/ru/en зроблені Claude — варто переглянути.
- Перемикання мови ще не перевірене в браузері (на момент змін не було `.env.local`) — перевірити після налаштування ключів.
- ✅ 2026-10-14 Supabase налаштовано (проєкт `finance-tracker`, Frankfurt), міграції 0001+0002 застосовані, користувач створений, вхід працює.
- ✅ 2026-10-14 Виправлено: нечитабельний список мов у темній темі → `color-scheme` у `globals.css` (стосується всіх нативних select/date).
- Dev-попередження «hydration mismatch» з атрибутами `bis_skin_checked` — від браузерного розширення (Bitdefender), не баг застосунку.
- Помилка «Missing or invalid Supabase env vars» = відсутній або неправильний `.env.local`.
- Проєкт лежить в OneDrive. Якщо `npm install` падає з EPERM — призупинити синхронізацію OneDrive.
- `npm audit` показує 5 high — у dev-залежностях скаффолду; перевірити перед деплоєм, `--force` не запускати.
- RLS не перевіряє, що `category_id`/`account_id` у транзакції належать тому ж користувачу (FK на чужий id теоретично можливий). Для одного користувача ризик нульовий; при потребі — композитні FK.
- Числа `numeric` приходять з PostgREST як JSON number → конвертуються в центи в `src/lib/data.ts` (`toCents`); у JS сумуються лише центи.
- **Безкоштовний Supabase призупиняє проєкт після 7 днів без активності** — дані зберігаються, у дашборді треба натиснути «Restore».
- Бюджети не переносяться автоматично на наступний місяць (у ТЗ не було) — можлива майбутня покращення «копіювати з попереднього місяця».
- Сторінка `/transactions` поки показує лише 100 останніх — пошук/фільтри/пагінація у Фазі 4.
- Іконки категорій — фіксований набір із 30 (`src/components/category-icon.tsx`), щоб не тягнути всі іконки lucide в бандл.
